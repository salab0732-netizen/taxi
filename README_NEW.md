## ما يفعله النظام

### للسائق:
- 🪪 **الهوية** — رفع CNI + رخصة السياقة بـ OCR تلقائي
- 🚗 **المركبة** — رفع البطاقة الرمادية بـ OCR تلقائي
- 🚪 **رقم الباب** — بيانات المستفيد + القرار الولائي + عقد الكراء
- 👤 **المناوب** — بيانات المناوب + عقد العمل (سنة، لا يتجاوز عقد الكراء)
- 📝 **الطلبات** — 9 أنواع طلبات، طباعة فورية، متابعة الحالة

### للمدير:
- 📊 إحصائيات شاملة (12 بطاقة)
- 📝 إدارة الطلبات (قبول/رفض/طباعة)
- 👥 ملفات السائقين الكاملة
- 🗄️ أرشيف المتوقفين نهائياً
- 📜 الشهادة التاريخية الشاملة
- 📥 تصدير CSV

---

## قواعد النظام
- لا شيء يُحذف — أرشفة كاملة دائمة
- OCR → مراجعة يدوية → حفظ
- عقد المناوب لا يتجاوز عقد الكراء
- تنبيهات قبل 30 يوم (تحذير) و7 أيام (عاجل)
