# 📱 تطبيق الهاتف (APK) — منصة تسيير سيارات الأجرة

التطبيق **غلاف (WebView)** لواجهة المنصّة نفسها. **قاعدة البيانات والوثائق تبقى على الحاسوب**
(`backend_new`)؛ الهاتف لا يحفظ أي بيانات، والواجهة تُحمَّل من الحاسوب في كل مرة، فأي تحديث
للواجهة يصل إلى الهاتف دون إعادة تثبيت التطبيق.

## الحصول على ملف APK
يُبنى تلقائياً على GitHub Actions عند كل تعديل في `mobile_apk/`:
GitHub ← Actions ← «APK تطبيق الهاتف» ← آخر تشغيل ← Artifacts ← `Taxi-mobile-apk` (ملف zip فيه `Taxi-mobile.apk`).
انقله إلى الهاتف وثبّته (اسمح بـ «تثبيت تطبيقات من مصادر غير معروفة»). يتطلب Android 10 أو أحدث.

## التشغيل
1. على الحاسوب: `start.bat` كالعادة (Backend + Frontend + ngrok).
2. في التطبيق: اكتب الرابط الظاهر في نافذة ngrok (مثل `https://xxxx.ngrok-free.app`) ثم «اتصال».
   - بديل بلا ngrok: عنوان الحاسوب في نفس شبكة Wi-Fi أو عبر Tailscale، مثل `192.168.1.10` (المنفذ 3000 يُضاف تلقائياً).
3. التطبيق يحفظ الرابط. إذا تغيّر (رابط ngrok المجاني يتغيّر عند كل تشغيل) تظهر شاشة الرابط تلقائياً،
   أو: زر الرجوع في الصفحة الرئيسية ← «تغيير رابط الحاسوب».

## ما يدعمه التطبيق
- كل صفحات المنصّة (السائق، الشركة، المدير `#admin`).
- رفع الوثائق للقراءة الآلية: الكاميرا أو المعرض أو PDF. صورة الكاميرا تُحذف من الهاتف بعد إرسالها.
- وثائق الطباعة: تُفتح فوق البرنامج، وزر «🖨️ طباعة» يفتح طباعة أندرويد (طابعة أو «حفظ PDF»). زر الرجوع يغلقها.
- تصدير Excel (البطاقة الجماعية…) يُحفظ في «التنزيلات» ويُفتح.
- الدخول بحساب Google غير متاح داخل WebView (قيد من Google) ← الدخول باسم المستخدم وكلمة السر.

## ملاحظات تقنية
- `window.TaxiApp` واجهة JS: `print(title)`، `saveFile(name, mime, base64)`، `changeServer()`، `version()`.
  `frontend_new/src/ui/kit.jsx` (`downloadFile`) يستعمل `saveFile` عند وجوده، وإلا يبقى سلوك المتصفح كما هو.
- وكيل المستخدم `TaxiApp/…` (ليس متصفحاً) يتجاوز صفحة تحذير ngrok المجاني.
